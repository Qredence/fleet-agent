apps/api

  • FastAPI backend, DSPy 3.3.1 engine.
  • 40 core Python modules across 6 packages + main/settings.
  • ~9,300 lines of Python source.

apps/web

  • React 19 + Vite + assistant-ui 0.15.
  • 60+ components, 8 feature modules, UI kit.
  • ~17,800 lines of TS/TSX.

packages/contracts

  • Single source of truth AgentWorkspaceState schema.
  • Deterministic AG-UI fixture streams.
  • Regenerates TS + Python models.

app/api

  • Thin REST/SSE routers.
  • No DSPy knowledge — talks to AgentEngine boundary only.

app/agent

  • Houses DSPy engines (ReActV2, staged) + factory + typed tools.
  • Raw dspy.History stays here/API-side.

app/agui

  • Maps domain events → AG-UI; trace diffs; live + fixture coordinators.
  • SCSS-free; enforces exactly-once terminal events.

components/

  • assistant-ui/ — conversation primitives, thread, inline run activity.
  • elements/ + process-panel/ — tool calls, sources, artifacts, file exploration.
  • ui/ — reusable Base-UI & Fluid Functionalism kit.

features/

  • agent-runtime — provider + AG-UI presence; owns runtime wiring.
  • threads / projects — data-fetching hooks + persistence sync.
  • tools / artifacts — API clients and renderers.

state & lib

  • Zustand store holds UI prefs only — never agent process state.
  • Process state read via useAgUiState<AgentWorkspaceState>().
  • lib provides API client, surface system, shared contexts.
