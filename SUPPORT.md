# Support

Fleet Agent is early-stage software. Please choose the channel that matches
your question so maintainers and other contributors can find it later.

- [GitHub Discussions](https://github.com/Qredence/fleet-agent/discussions) —
  setup questions, usage help, design discussion, and ideas.
- [GitHub Issues](https://github.com/Qredence/fleet-agent/issues) —
  reproducible bugs and scoped feature requests.
- [CONTRIBUTING.md](CONTRIBUTING.md) — local setup, repository boundaries, and
  validation requirements.
- [SECURITY.md](SECURITY.md) — security vulnerabilities and private reporting.

Before opening a public issue, search existing discussions and issues. Include
the commit SHA, operating system, browser, relevant Node/pnpm/Python/uv
versions, selected agent mode, reproduction steps, and expected versus actual
behavior. Remove API keys, provider prompts, raw reasoning, stack traces with
secrets, and private user data from all public reports.
